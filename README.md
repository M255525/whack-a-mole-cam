# 🔨 體感打地鼠

對著攝影機把手**由上往下用力一敲**就能打地鼠！3D 菜園裡 9 個洞，地鼠的臉可以**換成你上傳的照片**（最多 6 張、可裁切、可取名字），結算時看誰被敲最多次。

- 四種角色：地鼠 +10、黃金地鼠 +30、安全帽地鼠（敲兩下）、炸彈 −20（別敲！）
- 連擊加分、最後 10 秒「最後衝刺」分數 ×2
- 攝影機手部追蹤（MediaPipe HandLandmarker），雙手兩支槌子；也可改「手碰到就打」
- 無攝影機時可用滑鼠／觸控，或數字鍵 1～9
- 3D 場景：Three.js 程式繪製，無外部素材；本機排行榜、可加入主畫面（PWA）

直接用瀏覽器開 `index.html`（攝影機需在 `localhost` 或 HTTPS 下才能使用）。操作說明見 `manual.html`。
